❓ الأسئلة الشائعة

أسئلة مهمة

إجابات سريعة على أهم الأسئلة

املأ نموذج حجز الطيران وأرسل الطلب، وسنتواصل معك عبر واتساب بالخيارات والأسعار المتاحة.
نعم. يمكنك إرسال المدينة وتواريخ الإقامة وعدد الغرف والأشخاص.
نعم. يمكنك طلب باقة طيران وفندق، وسنبحث لك عن الخيارات المناسبة.
العروض والأسعار تختلف حسب تاريخ السفر والتوفر، لذلك يتم تأكيد السعر قبل الحجز.
يمكنك التواصل معنا مباشرة عبر واتساب من خلال أزرار التواصل الموجودة في الموقع.

🔐 الخصوصية

سياسة الخصوصية

نحترم خصوصية عملائنا وبياناتهم

جمع المعلومات

قد نجمع المعلومات التي تدخلها في نماذج الحجز مثل الاسم ورقم الهاتف وتفاصيل الرحلة.

استخدام المعلومات

تستخدم المعلومات لمتابعة طلب الحجز والتواصل مع العميل وتقديم الخيارات المناسبة.

واتساب

عند إرسال طلب الحجز عبر واتساب يتم فتح تطبيق واتساب لإرسال البيانات التي اخترت مشاركتها.

حماية البيانات

نلتزم باستخدام البيانات لغرض خدمة العميل ولا نبيع معلومات العملاء لأطراف أخرى.

الموافقة

باستخدام نماذج الحجز، يقر المستخدم بأنه اختار إرسال البيانات بغرض متابعة طلب السفر.

الشروط والأحكام


يتم التعامل مع طلبات الحجز بعد مراجعة التوفر وتأكيد السعر من قبل فلاي مسار.


إرسال نموذج الطلب لا يعني إتمام الحجز بشكل نهائي. يجب الحصول على تأكيد الحجز قبل الدفع أو السفر.


قد تختلف الأسعار والتوافر حسب شركة الطيران أو الفندق أو تاريخ السفر.


يتحمل المسافر مسؤولية التأكد من صحة بيانات السفر والوثائق المطلوبة قبل الرحلة.
